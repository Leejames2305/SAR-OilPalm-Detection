# Annual foundation embeddings and local contrasts

Source: Google Earth Engine GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL, AlphaEarth Foundations embeddings; 2023, 2024, and 2025 calendar years. API availability was explicitly queried and included 2025, despite the public catalogue page still describing availability through 2024. Bands A00..A63 are dimensionless components of unit-length embedding vectors (10 m native pixels), not physical reflectance. Each year includes point embedding (yYEAR_Axx) and embedding minus circular 40 m focal mean (cYEAR_Axx). Mosaics set EPSG:32648 10 m default projection; points sampled via reduceRegions(mean), scale10m, tileScale4. No labels used, no dimensionality selection on labels. Retained original 64 dimensions per year and contrast to enable reproducible downstream training-only PCA. This encodes prior-year habitat/canopy context, not current disease confirmation.

features.parquet: 7,220 rows x387 columns, all exact (estate,Long,Lat) source keys, zero duplicate keys, zero NaNs. Extraction script extract.py. Source tables are read once only to obtain coordinate keys; label column discarded immediately. Annual temporal changes are differences in corresponding embedding dimensions, not changes in reflectance. Citation: Brown et al., AlphaEarth Foundations, https://arxiv.org/abs/2507.22291; catalogue https://developers.google.com/earth-engine/datasets/catalog/GOOGLE_SATELLITE_EMBEDDING_V1_ANNUAL.
