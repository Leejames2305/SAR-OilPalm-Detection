# Label-free canopy-neighborhood optical texture

Source: COPERNICUS/S2_SR_HARMONIZED April15–August15 2026, linked Cloud Score+ cs_cdf>=.65 and SCL4 vegetation mask, median bands B2/B3/B4/B8/B5/B8A/B11; fallback March15–September15 SCL4 median. Harmonized SR DN/10000, no second offset. Reproject to 10m EPSG32648 before sampleRectangle; native red-edge/SWIR20m remains mixed. ee.Image.pixelCoordinates checks sampled image grid origin. getDownloadURL was denied thumbnails.create; reproducible extraction uses sampleRectangle computational endpoint instead (not a thumbnail). Patches 32x32 pixels (320m) around trunk; finite positive per-band support and within-chip median imputation, no labels. Coordinates projected to raster CRS before indexing.

NDVI=(NIR-red)/(NIR+red); NDRE=(B8A-B5)/(B8A+B5); NDMI=(B8-B11)/(B8+B11). Features use circular radii 10,20,40m: centre NDVI, med10, med40/background, med10-med40 contrast; NDVI SD20/40, ring10–30m mean minus centre (dip), central4x4 finite-difference gradient magnitude (edge); NIR/red SD20; NDRE/NDMI med10-med40 contrasts. Pixel centre index16 corresponds to trunk-containing pixel; integer pixel registration from projected origin. These are mixed-pixel canopy/stand features, not delineated crowns. All12 numerical covariates are label-free. features.parquet:7220x15, zero NaNs or duplicate keys; exact estate,Long,Lat source keys. extract_optical_chips.py builds source chip arrays under research/optical_chips; extract_texture.py derives this table. Both scripts retained. No label inference occurs during extraction.

Registration audit: ee.Image.pixelCoordinates returns centre values .5,1.5,..., not integer corner indices. Original raster affine used those as corners, shifting the saved geotransform +5m east and -5m south. Consequently the feature table samples an effective NW half-pixel view (when floor indexing changes), rather than exactly the trunk-containing pixel. This is a reproducible sampling displacement, not crown localization. The original verified table and scripts are preserved; corrected and registration-integrated versions live in optical_aligned/optical_jitter. Do not silently regenerate this table with corrected affine and assume score equivalence.
